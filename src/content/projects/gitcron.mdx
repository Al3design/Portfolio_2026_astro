        title: A desktop client for working with Git
        text: >-
          GitCron began with a personal need: managing Git through a friendly,
          intuitive interface rather than relying on the command prompt for
          everyday tasks. I wanted to bring those operations into a visual
          environment that I could navigate clearly.


          Over time, the project grew closer to my own working methodology. It
          continues to evolve: beyond repository management, it incorporates
          OpenSpec, diagrams for understanding project structure and AI
          assistance across different screens.
      - _template: section
        title: From a Git client to my working environment
        text: >-
          The project’s evolution connects three ways of looking at the same
          work. Git tracks changes; OpenSpec organizes the definition of the
          intended change; and diagrams help show how the project is built and
          structured.


          AI integration supports processes across the different screens. This
          combination has moved GitCron toward an interface tied to the way I
          work, keeping project context present when moving between planning,
          structure and changes.
