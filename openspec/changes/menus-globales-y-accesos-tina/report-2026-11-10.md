## Procedimiento de actualización

1. Coordinar detener la terminal dev del usuario con Ctrl+C; no matar procesos ajenos ni reinstalar mientras Tina está escribiendo.
2. Revisar versiones actuales, engines, peers y diff. Para las versiones consultadas, cambiar el override tinacms de pnpm-workspace.yaml a 3.15.2.
3. Usar el gestor del repo, sin package-lock nuevo:

```powershell
pnpm.cmd add --save-exact tinacms@3.15.2
pnpm.cmd add --save-dev --save-exact @tinacms/cli@4.0.5
```

4. Revisar package.json/pnpm-lock.yaml y peers; no cambiar React/Slate ni overrides ajenos para silenciar avisos. Reiniciar una vez `npm.cmd run dev` con el alcance autorizado; Tina regenera su esquema, admin y tina-lock. No editar generados. Comprobar flujo/tema/guardado al cierre; Cloud puede requerir reindexación de la rama autorizada. No omitir cloud checks ni repetir build previo por rutina.

Fuente oficial: https://tina.io/docs/guides/upgrade-to-latest-version. Documenta actualizar CMS y CLI juntos y regenerar lock. La actualización no se hace desde el aviso del sidebar.
