# Al3Design — isologo 2026

Cuatro SVG originales proporcionados por Alejandro Delgado. Se conservan sus paths, proporciones y colores, sin filtros CSS de inversion.

- isologo-A3D.svg: color original.
- isologo-A3D-white.svg: superficies oscuras.
- isologo-A3D-black.svg: impresion y usos monocromos claros.

Regenerar favicon.svg, favicon.png (32px), favicon.ico (16/32/48/64/128/256px) y apple-touch-icon.png (180px) con:

```sh
node scripts/generate-brand-icons.mjs
```

Los iconos usan el dibujo a color sobre una base clara para conservar legibilidad tanto en pestañas claras como oscuras. No son una reinterpretacion o una version simplificada del isologo.
