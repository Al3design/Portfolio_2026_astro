# Orden editorial desde Tina

Alejandro pidió poder cambiar el orden de los artículos desde Portfolio Overview y definir posiciones específicas dentro de sus categorías. El campo `order` ya alimenta el portfolio. El dashboard actual solo lo consulta y asigna un valor predeterminado diferente al del sitio.

El cambio incorpora edición explícita por fila, selección de ámbito general o categoría, persistencia mediante el cliente autenticado de Tina y un comparador compartido. Los números menores aparecen primero. Los valores existentes y el valor predeterminado público de cero se conservan.
