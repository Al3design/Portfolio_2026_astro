# Why

La rutina de OdontoPau aporta decisiones útiles, pero usa otro stack, hosting y flujo Git. El portfolio necesita entrada breve para IA local sin contradecir rama activa, checkout con trabajo previo ni política de controles.

# What Changes

- Skill propia, operación y prompts separados para alta, cambio focal y OK del Preview.
- Runner Node para candidato selectivo, sellado, integridad y sondas HTTP explícitas; sin publicación automática.
- Perfiles OpenCode Desktop y DSH propios, editor único y revisor opcional de lectura.
- Fuentes canónicas actualizadas; guías/scripts históricos identificados sin destruir evidencia.

# Impact

Solo instrucciones y herramientas operativas. Sin cambios al diseño/runtime público, contenidos reales, contratos, dependencias, ramas, worktrees ni despliegues. Validación acotada de herramientas nuevas; ensayo real en apps/Preview permanece separado hasta tener acceso/material y circuito remoto confirmados.
